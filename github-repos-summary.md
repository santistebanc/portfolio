## 🚀 Production-Ready / Featured Projects

### 1. **berlin-cinema** 
🔗 https://github.com/santistebanc/berlin-cinema  
📊 **Completion: 9/10**

A polished PWA for browsing original version (OV) and subtitled movies in Berlin cinemas. Features fuzzy search, dual source scraping (critic.de + berlin.de), TMDb/OMDb integration for metadata and ratings, cinema maps, dark/light theme, and automatic 6-hour data refresh via GitHub Actions. Deployed at **ovberlin.site**.

Tech: React 19, TypeScript, Vite, Tailwind CSS, Cheerio, GitHub Pages

---

### 2. **snapquiz**
🔗 https://github.com/santistebanc/snapquiz  
📊 **Completion: 8/10**

Real-time multiplayer quiz game built with PartyKit. Features screen mode (QR code display) and player mode (mobile join), WebSocket communication, and AI-generated questions via OpenAI API.

Tech: React, TypeScript, PartyKit, Tailwind CSS

---

### 3. **room-server**
🔗 https://github.com/santistebanc/room-server  
📊 **Completion: 8/10**

A generic PartyKit backend providing real-time KV storage, subscriptions, presence, atomic ops, broadcast, and scheduled jobs. Includes TypeScript SDK, HTTP REST API, and comprehensive documentation.

Tech: PartyKit, TypeScript, Cloudflare Durable Objects

---

### 4. **autocomplete-react**
🔗 https://github.com/santistebanc/autocomplete-react  
📊 **Completion: 9/10**

Reusable React autocomplete component with keyboard navigation, match highlighting, and flexible data fetching via Array, Function, or Promise. Has live demo deployed.

Tech: React, Webpack, Babel

---

### 5. **roundRobin**
🔗 https://github.com/santistebanc/roundRobin  
📊 **Completion: 8/10**

Highly configurable round-robin tournament bracket generator supporting multiple players per match. Uses Web Workers to prevent UI blocking and includes smart player randomization.

Tech: React.js, Baobab data tree

---

### 6. **my-crawler**
🔗 https://github.com/santistebanc/my-crawler  
📊 **Completion: 8/10**

A Fastify server with Crawlee/Playwright web scraping capabilities that extracts flight data from flightsfinder.com using both Kiwi and Sky portals in parallel. Includes parameter mapping and detailed segment extraction.

Tech: Fastify, TypeScript, Crawlee, Playwright

---

### 7. **cors-anywhere** (fork)
🔗 https://github.com/santistebanc/cors-anywhere  
📊 **Completion: 10/10**

Active fork of Rob--W's popular CORS Anywhere NodeJS reverse proxy. Adds CORS headers to proxied requests with configurable origin whitelisting, rate limiting, and cookie handling.

Tech: Node.js, http-proxy
